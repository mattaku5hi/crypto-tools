Read-only audit from 2026-10-13 20:03:46 UTC through 20:06:30 UTC. The frozen 2026-10-13 priority cohort initially contained 96 Solana `codex-missing` rows. Each had a cached Solana Tracker price, millisecond timestamp, exact pool ID, and response hash. The private inventory retains the original 96-row selection basis, while the GT request manifest preserves actual UTC timestamps.

## GT method and outcome

For each of eight selected mints, I requested public GT pool metadata, then the pool's daily OHLCV with `aggregate=1`, `limit=3`, `currency=usd`, `token=<exact mint>`, and `before_timestamp` at the UTC peak-day end. Requests were sequential, at least 10 seconds apart (minimum measured start spacing 10.46 seconds), with a 20-second timeout, 2 MiB response cap, and no retries. Sixteen HTTP attempts were made. One pool-metadata request returned HTTP 429; no retry followed. The OHLCV response for that token still carried exact base/quote addresses and was independently identity-checked.

The comparison uses same-day GT daily high versus the published ST maximum price, so both sides are extrema of the same price kind. Three cases pass the authorized 2% price gate and have exact target-token/quote identities:
