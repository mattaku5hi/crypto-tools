# Base e465 historical supply and source audit

Scope is the e465 price event from the cached event-ordered V4/ZORA audit, through that event only. This is read-only evidence; no ATH or FDV database write was made.

The target is `0xe46504da7f7f9d9233d6118e27bdfbf27964a215`. Its cached annual price observation is the V4 pool `0xf1661e6dbbde59e76f9b620e859431180cfb107849a82d6eac12300758a6f0f5`, at block 51,792,272, transaction `0xbac14a57c0b945cc2d7c3176765900f1fa9648fcdc658269da1b834c84971c5f`, log index 366, 2026-09-25 22:04:51 UTC. The successful creation transaction receipt places deployment at block 51,693,504 (2026-09-23 15:12:35 UTC), hash `0x622a208843f7465353b66fe53d71d1965a3a2130116833fc543cd751f088f658`. Its target-token Transfer mint log is at index 468 and mints exactly `1,000,000,000 × 10^18` raw units. At both creation and the annual price block, `decimals()` returns 18 and `totalSupply()` returns `1000000000000000000000000000`. The complete `eth_getLogs` mint scan from creation through the price block returns that one mint; the corresponding burn scan returns no logs. The peak swap receipt is successful and its block hash matches the exact V4 Swap log row.

At both historical heights the token runtime is the same 45-byte EIP-1167 minimal proxy pointing to `0x5dbd43785954d43c1643a0caf2ecef9e0056ff13`. The implementation runtime hash at both heights is `51caba906ac5b816aaf91fb17bfa6cfe3d84211e2ea1af39bc2bbdf9ac8d8373`, matching the earlier Base Zora implementation audit, whose Sourcify record is an `exact_match` for creation and runtime. This is an implementation-source identity reuse, not a claim that Sourcify separately verified the e465 proxy address.

There was one superseded probe mistake: the initial calls labeled “creation” used block `0x3160f80` (51,777,408), based on an incorrect creation height. Those raw calls remain preserved and are explicitly excluded. The corrected height `0x314c7c0` (51,693,504) is supported by the successful creation receipt and launch record; corrected code, decimals, supply, mint and burn requests are calls 17–24 in the manifest.

The RPC audit used 24 bounded calls, with no retries, a 25-second timeout, and a 2 MiB response cap. Chain ID is 8453 and the saved anchor hash at block 52,456,236 matches the prior source audit. Raw responses, request parameters, status, response hashes, and the excluded probe note are in `.scout-data/diagnostics/base-e465-supply-source-audit-2026-10-11/manifest.json`. The original cached price evidence is `.scout-data/diagnostics/empty-cohort-v4-quote-route-audit-2026-10-11/event-ordered-pricing.json`; its target raw response SHA-256 is `29b2ad50e84645702301806f019fc5207ac79f4ea2fc39c562b9d670d39c0c6b`.

**Result:** supply is proven constant at 1 billion tokens through this observed price event, and the historical decimals/source implementation are supported. This closes the supply/source uncertainty for this event; it does not establish lifetime price-history completeness or authorize an ATH/FDV write by itself.
