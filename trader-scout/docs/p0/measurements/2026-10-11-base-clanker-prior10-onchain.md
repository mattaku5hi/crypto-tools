# Base Clanker prior-10 onchain price audit

As of 2026-10-11, this read-only audit covered the ten Base Clanker tokens in `.scout-data/diagnostics/remaining-priced-after421-2026-10-11.json` that the task selected from the earlier fixed-supply cohort. Each token has verified source evidence and a chain-evidence record for 100,000,000,000 tokens at 18 decimals (raw supply `100000000000000000000000000000`), with one creation mint and no burns, at Base block 52,456,236 (`0x3206b2c`, hash `0x021113f4f7d0a2fe23e0036948b341ef7bbe5c75a604eb56f96c8a873d5e39b8`). The per-token source/supply paths and hashes are in the diagnostic `analysis.json`.

The audit reused the cached Initialize identity scan and prior complete Swap scans for 00b0, 385ad, and 5b2a. It added 25 whole-range `eth_getLogs` reads for the remaining seven tokens (820 returned logs), plus exact-peak receipt, block-header, and USDC `decimals()` reads for all ten tokens. Total logical RPC use in the new artifact was 57, including chain and pinned-anchor preflight. All new logs were filtered by PoolManager address and indexed pool ID, from token creation through the same pinned anchor. Amounts were decoded as signed int128 `amount0`/`amount1` per the existing V4 decoder and compared as exact raw ratios after applying verified 18-decimal token and 6-decimal USDC scales. Each reported maximum has a successful receipt containing the exact Swap log, matching receipt/header block hash, and a 6-decimal USDC response at that block.

For USD sensitivity, each event-day USDC execution ratio was multiplied by the cached Kraken USDC/USD daily low and high. The ranges below are daily sensitivity bounds, not timestamp-level quotes. The 1% threshold is unchanged; both endpoints must fall inside it, and the execution maximum must share the reference's UTC day. No new market-provider requests or database writes were made.
