# Robinhood Chain alternative pool and launchpad coverage — 2026-10-14

## Finding

The frozen 35-token audit only checked the configured Uniswap v4 PoolManager. Two additional first-party sources document mainnet launch or pool paths that can be indexed independently: Goo Exchange and 4.fun. This is a deployment-discovery lead, not evidence that any of the 35 tokens traded on either venue. No RPC, explorer API, provider, or database calls were made for this note.

Robinhood’s own ecosystem announcement also names Pleiades as a proprietary AMM. I found no first-party Pleiades deployment address or event/indexing specification in this bounded search, so it is an unresolved candidate rather than a scan target. The same announcement lists Rialto and other wallet trading integrations; an integration name alone does not establish a permissionless pool factory or a historical price source.

## Recommended bounded scan

For each of the 35 exact addresses, use the configured Robinhood archive endpoint with a recorded chain ID 4663 and pinned block anchor. Scan the four documented factories (Uniswap v2, Uniswap v3, Goo V3, and GooLaunchpad) from verified deployment blocks through the anchor. Query indexed token positions in both orientations; record all successful, failed, and over-limit ranges separately. Resolve emitted pool addresses and verify token0/token1 or the factory’s own launch mapping before reading swaps. For each pool, start at its creation block and retain creation-transaction swaps as bootstrap rows rather than post-creation trading. This is a bounded additional four-factory pass; do not widen to unrelated contracts based on ticker/name matches.

Because Goo launch tokens quote in GOO and 4.fun permits stock-token quotes, a discovered pool is not yet a USD price. Only compare to a dated quote/USD source after proving the quote contract and its price interval at the same event time. Pool `Swap` execution ratios are executed prices, not automatically marginal-state highs or complete token ATHs.

## Result boundary

This note adds verified venue leads and a scan plan. It does not assert complete RH DEX coverage, prove the 35 tokens were launched on these platforms, or convert the configured-v4 empty windows into zero prices. A successful scan can establish only the observed histories of the discovered pools; lifetime ATH completeness still depends on resolving every relevant launch, migration, quote route, and price-history gap.
