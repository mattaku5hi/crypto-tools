# PumpSwap buyback event tail: dated schema check

As of 2026-10-14, the previously unexplained 16-byte suffix on the sampled Apr 28 and May 3, 2026 PumpSwap `BuyEvent`s is explained by the official Pump Swap SDK 1.15.0 IDL. The npm registry records that release at 2026-04-22 20:53:26 UTC, before the three extended payloads (one Apr 28 event and two May 3 events). Its `pump_amm.json` adds two `u64` fields after the cashback fields: `buyback_fee_basis_points` and `buyback_fee`. The extracted IDL SHA-256 is `c016da5a298532dfffcf97d77edb7fd06aeb790ba10af80f7b20979bc5fdbe74`; the SDK tarball SHA-256 is `ec91533f65232928371999a3c069c1d36cee2fb2428e3c63fa1aaa0c378461dd`, and its registry SHA-512 integrity value matched the downloaded tarball. [Official npm release metadata](https://registry.npmjs.org/@pump-fun%2fpump-swap-sdk), [SDK 1.15.0 package](https://www.npmjs.com/package/@pump-fun/pump-swap-sdk/v/1.15.0).

An independent, later repository snapshot contains the same fields: `pump-fun/pump-public-docs` commit `3c6721a67c0b206b39130b454c8ba22a83ce972e` (May 18, 2026) modifies `idl/pump_amm.json` to add the buyback pair. This is corroboration only; the commit postdates the events. The dated SDK release is the evidence that the schema existed before them. Neither source alone proves which program binary was deployed for a particular transaction. [Official repository IDL at that commit](https://github.com/pump-fun/pump-public-docs/blob/3c6721a67c0b206b39130b454c8ba22a83ce972e/idl/pump_amm.json), [commit change](https://github.com/pump-fun/pump-public-docs/commit/3c6721a67c0b206b39130b454c8ba22a83ce972e).

The versioned replay decoded the complete sampled payloads with no unparsed suffix: EWbabspX had 14 pre/post states under the earlier February IDL, FLkQktRL had 2 and 2b4p8ien had 4 under SDK 1.15.0. EWbabspX’s April 10 window predates that SDK release, so it retains the earlier applicable schema. For each mint, the captured maximum state within the existing ±3-second transaction window remained within 2% of the Solana Tracker provider-window price at both Coinbase minute-candle endpoints. The old February-IDL replay is preserved unchanged: it passed EWbabspX but left FLkQktRL and 2b4p8ien unresolved. The SDK 1.15.0 replay resolves those schema gaps without rewriting that earlier result.

This is a bounded decoder/schema and price-window cross-check, not lifetime ATH evidence, full transaction-history coverage, or proof of complete pool coverage. It does not establish the deployed binary version or change the project's source/supply qualification policy. The private reproducibility artifacts are `solana-gap-closure-2026-10-14-batch13/idl-tail-schema-offline-audit-v2.json` and `solana-gap-closure-2026-10-14-batch13/offline-price-proof-v2-sdk-1.15.0.json`.
