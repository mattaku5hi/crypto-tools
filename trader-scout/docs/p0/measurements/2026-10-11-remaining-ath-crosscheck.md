## Result

Six Base addresses were selected from the saved `potential_runner_metadata_clear` candidate cohort: at least 100 holders, `codex-missing` in the runner snapshot, and positive Birdeye daily-window highs. I prioritized the six largest Birdeye USD/token highs using exact decimal comparisons; the six current Codex snapshots independently have `extrema: null`. Each address was queried once through DexPaprika’s public token endpoint with no key. All six requests returned HTTP 200, but every response had `price_stats: null`, `summary.price_usd: null`, and `summary.fdv: null`. Consequently this is a metric-availability check, not a numerical cross-provider ATH validation: there is no DexPaprika ATH price/date to compare, so the observations neither validate nor contradict Birdeye’s peaks. A successful token metadata response is not a successful ATH lookup.

The first-party [token-latest endpoint reference](https://docs.dexpaprika.com/api-reference/tokens/get-a-tokens-latest-data) documents token data but not the runtime `price_stats.ath` field previously seen on other samples; the referenced [OpenAPI source](https://github.com/coinpaprika/skills/blob/main/dexpaprika-api/references/openapi.yml) likewise omits it. DexPaprika’s [pricing page](https://dexpaprika.com/api/pricing) says Free has token endpoints and 100K credits/month with a key, and that keyless access works for local testing subject to shared IP limits. The live requests here were keyless; no plan or quota account was used. The page also says Free pool OHLCV covers only seven days, so this does not provide a free full-history candle route to independently rebuild ATH.

## Method and limits

One ordinary unauthenticated GET per address, in descending Birdeye-window-high order; requests were spaced by 2.2 seconds, connect/read timeouts were 15/25 seconds, response bodies were capped at 2 MiB, and no retry was made. Numeric JSON was parsed with `Decimal`; untouched response bodies were archived and hashed. The private [comparison manifest](../../../.scout-data/diagnostics/dexpaprika-runner-crosscheck-2026-10-11/manifest.json) records exact request URLs, body hashes/lengths, response fields, candidate joins, Birdeye values/bar counts, and Codex-null snapshots; raw JSON is in its `raw/` directory. The upstream evidence snapshots are `logs/birdeye-runner-potential-20261011.log`, `.scout-data/diagnostics/ath-unknown-runner-potential-2026-10-11.json`, and `.scout-data/diagnostics/codex-explicit-unknown-refresh-2026-10-11/3-base-raw.json`, `4-base-raw.json`, and `5-base-raw.json`.
