# Axiom wallet PnL (read-only)

Небольшой read-only CLI для проверки списка публичных кошельков в Axiom через отдельный профиль Yandex Browser. Программа не просит ключи кошельков, не добавляет кошельки в tracker, не торгует и не импортирует tracker. Поддерживаются только Solana и BSC, для которых подтверждены отдельная идентичность сети и поля Performance.

## Требования

Python 3.10+ и установленный Yandex Browser. Playwright закреплён на версии 1.63.0:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
```

## Ручной вход

Откройте отдельный постоянный профиль браузера и войдите в Axiom вручную:

```sh
python axiom_pnl.py login --profile ~/.local/share/crypto-tools/axiom-wallet-pnl/profile
```

Не вводите пароли в CLI. Не публикуйте профиль: он содержит локальную сессию.

## Список кошельков

JSON принимает массив строк/объектов или объект с `wallets`; CSV принимает те же поля. Поддерживаются `wallet`, `address`, `trackedWalletAddress`. Для EVM требуется `chain` в каждой строке или общий `--chain`; сети не объединяются. В этой версии принимаются `solana` и `bsc`.

```json
[
  {"address":"0x1111111111111111111111111111111111111111","chain":"bsc","label":"example"},
  {"wallet":"11111111111111111111111111111111","chain":"solana"}
]
```

```sh
python axiom_pnl.py collect --input wallets.json --cdp-url http://127.0.0.1:9225 --out run-2026-10-12
python axiom_pnl.py collect --input wallets.csv --chain bsc --cdp-url http://127.0.0.1:9225 --out run-bsc
python axiom_pnl.py collect --input wallets.csv --chain bsc --min-30d-usd 5000 --min-max-usd 15000 --cdp-url http://127.0.0.1:9225 --out run-bsc-half-thresholds
python axiom_pnl.py collect --input wallets.json --delay-seconds 10 --cdp-url http://127.0.0.1:9225 --out run-slower
python axiom_pnl.py collect --input wallets.json --cdp-url http://127.0.0.1:9225 --out run-2026-10-12 --resume
```

Вход ограничен 16 MiB и 100 000 строками. Команда проверяет формат адресов и дедуплицирует только пару `(chain, wallet)`, сохраняя исходные метаданные первой строки. Пороговая логика требует одновременно Total PnL и Realized PnL не ниже `$10,000` за 30 дней и не ниже `$30,000` за Max. Все четыре значения берутся только из USD-подписанных Performance UI строк и сравниваются через `Decimal` с интервалом округления по показанной точности (`$483.5`, `$10.45`, `$10K`); без знака `$` значение неизвестно. Если интервал пересекает порог, статус `UNKNOWN`. Ответ `/portfolio` нужен для привязки свежего запроса к точному адресу/сети; его `realizedUsdPnl` сохраняется только в provenance как диагностическое значение и не заменяет UI-метрики, не меняет статус и не исключает кошелёк при расхождении.

Выход содержит `all.csv`, `all.jsonl`, `passed.csv`, `passed.json` и `manifest.json`; файлы и каталог создаются с правами только для владельца. CSV разворачивает денежные значения в raw/lower/upper/exact колонки, JSON сохраняет полную структуру. `all` сохраняет PASS/FAIL/UNKNOWN в исходном порядке; `passed` сортируется по убыванию нижней границы Max Total PnL, с отсутствующими значениями в конце. `as_of` в манифесте — время старта запуска и checkpoint, а не зафиксированный исторический срез: Axiom читается live последовательно, у каждой строки есть собственный `collected_at`. Проверенный контракт сейчас задает Axiom `timeOffsetMinutes=-180` для окна 30d. Resume прекращается при изменении порогов, source policy, as-of или упорядоченного списка сетевых идентичностей. Retryable записи не считаются окончательно завершенными.

`collect` подключается через CDP к уже открытому Yandex Browser на loopback URL и создает собственную вкладку. Он не запускает и не закрывает подключенный браузер. Карточка кошелька выбирается по точной сети, запрос и ответ `/portfolio` сверяются с адресом, а заголовок модального окна и активный период должны совпасть. Нативный `totalPnl` API не используется как USD.

При необходимости входа используйте `login`, войдите вручную и оставьте браузер открытым. `--delay-seconds` задаёт паузу между кошельками (2–120 секунд). Ошибка авторизации, CAPTCHA или rate limit сохраняет checkpoint и останавливает проход; при 429 дождитесь cooldown Axiom перед `--resume`, не пытайтесь обходить лимит увеличением параллелизма. Никакие пароли, cookies, заголовки или HAR не записываются.

Проверка offline core:

```sh
python3 -m unittest discover -s tests -v
```

Проверено 2026-10-12: 25 offline-тестов, компиляция Python и чтение двух заранее выбранных кошельков — одного SOL и одного BSC — в авторизованном Yandex Browser. Оба прошли четыре порога; сверены USD-показатели, сеть, выходные файлы и сохранение пользовательской вкладки. Проверенный завершённый `--resume` не подключается к браузеру повторно. Массовые списки не запускались.

Инструмент проверяет опубликованные показатели Axiom. Методика его бухгалтерии отдельно не аудирована; изменения интерфейса или ответа API могут потребовать обновления адаптера. Неподтверждённые значения остаются `UNKNOWN`.
